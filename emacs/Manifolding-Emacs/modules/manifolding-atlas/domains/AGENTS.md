# domains — one directory per capability

Each <domain>/<domain>.org is loaded by manifolding-emacs (#+priority:).

Domains: search, backup(git), capture(avy region/heading capture),
citation, contacts, dictionary, links, live-properties, manifold(mind map),
mastering(spaced repetition), properties(SPC v P + captures share the
custom *Atlas Grid* engine in properties.org — one menu, two modes;
rows auto-follow schema/*.org outlines, single source of truth),
protocols,
recipes, routines(atomic/composite/chain build + buffer runner + session
journaling + streaks/report), rules, schema(schema defs; index action
silent — violations only via MISSING PROMPTS; template schemas enforce
declared props via TEMPLATE_HASH),
schema-reinforcement(sweeps→MISSING PROMPTS, debounced triggers, boot
sweep, save-guard, registry audit), transclusion.

plugin-guide.org: authoritative authoring reference (disabled doc file).
Keybindings: SPC v hydra in modules/keyboard.org.
