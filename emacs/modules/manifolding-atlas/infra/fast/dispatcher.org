#+title:      Fast Captures Dispatcher
#+priority:   15

Dynamic dispatcher that scans infra/fast/ for capture org files and
presents a hydra menu.  New capture types are picked up automatically.

* Core

** Bindings builder
Discovers sibling capture org files and maps their first letter to the
matching `my/manifolding-atlas-quick-<name>' command.
#+begin_src emacs-lisp
(defun my/manifolding-atlas-quick--bindings ()
  "Return hydra binding specs for every discoverable quick capture."
  (let* ((dir (my/manifolding-atlas-infra-fast-dir))
         (files (seq-filter
                 (lambda (f)
                   (and (not (file-directory-p (expand-file-name f dir)))
                        (not (string= f "dispatcher.org"))))
                 (directory-files dir nil "\\.org\\'"))))
    (delq nil (mapcar (lambda (f)
                        (let* ((name (file-name-sans-extension f))
                               (fn (intern (concat "my/manifolding-atlas-quick-" name))))
                          (when (fboundp fn)
                            (let ((key (char-to-string (aref name 0)))
                                  (label (capitalize name)))
                              `(,key ,fn ,label :exit t)))))
                      files))))
#+end_src

** Dispatcher command
Regenerates the hydra on every call so new capture files are picked
up without reload.
#+begin_src emacs-lisp
(defun my/manifolding-atlas-quick-captures ()
  "Choose a fast capture type via hydra menu."
  (interactive)
  (eval (macroexpand
         `(defhydra my/quick-captures-hydra
            (:title "Fast Captures" :quit-key "q" :separator "─")
            "Actions"
            ,@(my/manifolding-atlas-quick--bindings))))
  (my/quick-captures-hydra/body))
#+end_src
