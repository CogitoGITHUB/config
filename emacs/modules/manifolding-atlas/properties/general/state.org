* State
Why: Current-state register. What exists, what is complete, what is degraded, what is blocked. A live contrast between the Blueprint and reality. If this file is optimistic, it is lying to the Architect.

** Default (default WARNING)
#+begin_src emacs-lisp
(defun my/manifolding-atlas-prompt-state ()
  "Prompt for WS_STATE. Returns \"WARNING\" if skipped."
  (let ((val (completing-read
              "WS_STATE: "
              '("⚠ WARNING" "SYNCED" "DRIFTED" "BLOCKED" "UNKNOWN")
              nil t nil nil "⚠ WARNING")))
    (if (string-equal val "⚠ WARNING") "WARNING" val)))
#+end_src

** Registration
#+begin_src emacs-lisp
(my/manifolding-atlas-register-prompt
  :key 'state
  :name 'state
  :label "State"
  :prompt-fn #'my/manifolding-atlas-prompt-state
  :contexts '(file heading task)
  :read-current-fn (lambda () (org-entry-get nil "WS_STATE"))
  :merge-strategy 'replace
  :to-plist (lambda (val _ctx)
              (if (or (null val) (string-equal val "WARNING"))
                  `(:properties (("WS_STATE" . "WARNING")))
                `(:properties (("WS_STATE" . ,val))))))
#+end_src
