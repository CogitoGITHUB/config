This file is the bootstrap kernel.  It tangles to ~init.el~ and
~early-init.el~ — the two files Emacs loads automatically at startup.

*How it works:*
- Each section below tangles to a specific file via ~:tangle~.
- After editing this file, run ~org-babel-tangle~ to regenerate:
  #+begin_src sh :eval no
  emacs --batch -l org --eval "(org-babel-tangle-file \"~/.config/emacs/bootstrap.org\")"
  #+end_src
- The tangled ~init.el~ and ~early-init.el~ must *not* be edited
  directly — treat them as build artifacts.

*Why this exists outside ~modules/~:*
Everything here must run before ~manifolding-emacs-boot~ processes the
org modules under ~modules/~.  Putting it in an org module would be
circular (the boot system itself isn't loaded yet).

** Straight.el Bootstrap
Must be here — loading straight.el must happen before any straight-use-package call.

#+begin_src emacs-lisp
(defvar bootstrap-version)
(let ((bootstrap-file
       (expand-file-name "straight/repos/straight.el/bootstrap.el" user-emacs-directory))
      (bootstrap-version 6))
  (when (file-exists-p bootstrap-file)
    (load bootstrap-file nil 'nomessage)))
#+end_src

** Git SSL CA cert fix
Must be here — straight clones need GIT_SSL_CAINFO before any HTTPS fetch.

#+begin_src emacs-lisp
(when (file-exists-p "/etc/ssl/certs/ca-certificates.crt")
  (push "GIT_SSL_CAINFO=/etc/ssl/certs/ca-certificates.crt" process-environment))
#+end_src

** Org from GNU ELPA
Must be here — packages loaded during boot depend on the latest Org.
If this runs too late, the built-in Org loads first and causes
version-mismatch warnings.

#+begin_src emacs-lisp
(straight-use-package 'org)
#+end_src

** Leaf & Leaf-Keywords
Must be here — manifolding-emacs-boot generates leaf forms.

(straight-use-package 'leaf)

** Manifolding-Emacs
The literate boot system.  Processes all modules/*.org.

#+begin_src emacs-lisp
(mapc (lambda (d) (add-to-list 'load-path (expand-file-name d user-emacs-directory)))
      '("lisp/" "lisp/manifolding-emacs/"))
(require 'manifolding-emacs)

(setq manifolding-emacs--boot-warnings '())
(advice-add 'manifolding-emacs-boot :before
            (lambda () (setq manifolding-emacs--boot-warnings '())))
(advice-add 'display-warning :before
            (lambda (type message &rest _)
              (push (list :type type :message message)
                    manifolding-emacs--boot-warnings)))

(setq manifolding-emacs-package-method 'leaf
      manifolding-emacs-org-directory (expand-file-name "modules" user-emacs-directory)
      manifolding-emacs-output-directory (expand-file-name "manifolding-emacs" user-emacs-directory))
(setq inhibit-startup-screen t)
(manifolding-emacs-boot)

(global-auto-revert-mode 1)
(setq auto-revert-verbose nil
      revert-without-query '(".*")
      global-auto-revert-non-file-buffers t)
#+end_src
